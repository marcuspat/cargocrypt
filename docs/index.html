What it does

Zero-config encryption

ChaCha20-Poly1305 + Argon2id for Rust projects — no key ceremony, no YAML: drop it in and encrypt.

Secrets stop at the hook

Git hooks scan for secrets before they enter history, not after they leak.

TUI included

A terminal interface for encrypt, decrypt and inspect — built for real workflows, not demos.

cargo install cargocrypt
